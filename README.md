# OCSecure

Oracle Database 테이블 컬럼에 대한 양방향 암복호화 및 일방향 암호화 모듈 개발 프로젝트입니다.

아울러 해당 모듈이 임의로 분석되거나 변조되지 않도록 하는 접근권한 통제 체계의 구축까지를 범위에 포함합니다. 사업은 프로그램 개발 트랙과 보안관리 트랙으로 분리하여 추진하며, 두 트랙을 분리하는 이유는 분량 때문이 아니라 모듈을 만드는 주체와 통제하는 주체가 분리되어야 통제가 성립하기 때문입니다.

## 문서 구성

`docs/00_종합계획.md`는 최상위 추진 계획입니다. 전제와 미확정 사항, 두 트랙의 분리 근거와 접점, 일곱 단계 로드맵, 산출물과 역할 분담, 초기에 확정해야 할 네 가지 의사결정 분기점, 위험 관리와 성공 기준을 담고 있습니다.

`docs/10_암호화모듈_개발설계.md`는 개발 트랙의 설계서입니다. 양방향과 일방향의 분류 기준, 아키텍처 대안 비교와 권고, 삼계층 모듈 구조, 암호문 포맷과 알고리즘 선정, 키 관리와 교체 절차, 검색을 위한 색인 설계, 애플리케이션 투명화 전략, 성능 설계, 데이터 전환 절차와 시험 계획을 담고 있습니다.

`docs/20_보안관리_접근통제설계.md`는 보안관리 트랙의 설계서입니다. 위협 모델과 통제 원칙, 소스 은닉 수단의 한계에 대한 평가, 계정과 스키마 구조, 데이터베이스 관리자에 대한 통제, 실행 경로 통제, 변경 통제와 무결성 감시, 감사와 이상 탐지, 남용 방지, 통제 유효성 점검 시나리오와 잔여 위험을 담고 있습니다.

## 현재 상태

설계 단계이며 구현 산출물은 아직 없습니다. 다음 작업은 종합계획 제2절에 정리된 다섯 가지 미확정 사항의 확정입니다. 특히 검증필 암호모듈 사용 의무 여부와 오라클 에디션 및 유상 옵션 보유 현황은 다른 모든 설계에 선행하여 확인되어야 합니다.
